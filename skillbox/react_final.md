UI
+ В приложении реализована главная страница в формате дашборда.
+ Пользователь может просматривать случайный фильм, получать новый фильм по кнопке обновления, а также видеть список топ-10 фильмов по IMDb-рейтингу. Все карточки фильмов корректно открывают страницу с подробной информацией.

+ Функция поиска фильмов работает через модальное окно. Поиск выполняется по названию фильма, результаты отображаются корректно и обновляются динамически.

+ Страница жанров отображает список доступных категорий фильмов в виде карточек. При выборе жанра открывается отдельная страница, где фильмы фильтруются по выбранной категории. Реализована постраничная подгрузка фильмов при прокрутке страницы.

+ На странице фильма присутствует полное описание, кнопка просмотра трейлера и функционал добавления фильма в избранное. Трейлер открывается в модальном окне и воспроизводится корректно. При попытке добавить фильм в избранное без авторизации отображается форма входа или регистрации.

+ Модальное окно авторизации реализовано согласно требованиям ТЗ. Поддерживаются формы входа и регистрации, все поля проходят обязательную валидацию. При незаполненных полях отображается визуальная индикация ошибок. После успешной авторизации кнопка «Войти» заменяется фамилией пользователя.
+ Страница аккаунта содержит информацию о пользователе и список избранных фильмов. Реализован корректный выход из аккаунта с последующим переходом на главную страницу.

- Нет задержки для поиска. Задержка поиска (debounce) важна для уменьшения количества запросов к API. Без неё запрос отправляется при каждом вводе символа, что создаёт лишнюю нагрузку на сервер и может вызывать «скачки» интерфейса из-за постоянного обновления результатов.
