Метод findElement ищет элемент, но не гарантирует, что он уже появился и стал видимым. Т.е. после загрузки страницы динамические элементы могут появляться с задержкой. Лучше использовать until:

const { By, until } = require('selenium-webdriver');

await this.driver.wait(
  until.elementLocated(By.css('.site-logo')),
  5000,
);

const logo = await this.driver.findElement(By.css('.site-logo'));

await this.driver.wait(until.elementIsVisible(logo), 5000);

Так тест будет устойчивее к задержкам загрузки страницы.

# 
Также метож isEnabled() проверяет только доступность элемента, но не гарантирует, что по нему действительно можно кликнуть. Например, у ссылки может быть перекрывающий элемент, который мешает взаимодействию.Лучше дополнительно использовать:

await this.driver.wait(
  until.elementIsVisible(loginLink),
  5000,
);

await this.driver.wait(
  until.elementIsEnabled(loginLink),
  5000,
);
